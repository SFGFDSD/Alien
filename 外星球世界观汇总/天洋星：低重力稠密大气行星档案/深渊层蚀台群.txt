## 深渊层蚀台群
---

### 一、宏观形态：不是个体，是“阵地”

它们不是一个生物，而是一群。  
每一群被称为一个 **“炮台巢”**。

一个炮台巢覆盖的面积从 **数百平方米** 到 **数万平方公里** 不等 目前最大的单个不算结盟阵地覆盖面积为8,800万平方公里。  
远远看去，这片区域就像一张布满脓疱的、腐烂的黑色地毯。无数个直径 **2至8米** 的球状囊体，半埋在“有机雪”中，只露出一小部分，表面覆盖着与残骸同色的污浊斑纹，几乎完全伪装成普通的地表堆积物。

你无法一眼看出它们是活物——它们看起来太像“地形”本身了。

---

### 二、内部结构：硬编码的战争机器

*炮台巢并非一个多细胞生物，而是由数十万到数百万个功能高度分化的“炮台个体”组成的分布式聚合体。它们的“智慧”不来自神经元，而来自化学开关和物理阀门。*

#### 个体类型：

| 个体类型 | 功能 | 形态 |
|:---|:---|:---|
| **感知柱** | 侦察 | 极细的羽状触须，竖立在有机雪表面3-5米高，像一片枯死的草。内部有气压感应腔。 |
| **播种囊** | 繁殖/扩张 | 拳头大的小球体，内部充满轻质孢子，成熟时会裂开，孢子上浮到空中。 |
| **主战浮囊** | 攻击 | 核心攻击单位。详见下文。 |
| **根脉网** | 营养/通信 | 一种埋在有机雪下的菌丝状网络，将所有个体连接成一个整体，传递化学信号和营养物质。 |

| **迫击囊** | 曲射压制 | 短粗的囊体，底部更厚、顶部较薄。爆炸时碎片呈抛物线散布，覆盖范围广，专门打击较远或隐蔽的目标。 |
| **穿甲锥** | 破防/攻坚 | 纺锤形硬质囊体，内部填充液态金属盐。爆炸时形成定向射流，可熔穿敌方厚实的根脉网或核心囊体。 |
| **喷火腐** | 面杀伤/纵火 | 扁平如饼的囊体，内含高粘度焦油。爆炸后不产生冲击波，而是向四周喷射粘稠燃烧物，点燃大面积有机雪。 |
| **烟幕囊** | 遮蔽/干扰 | 内部充填极细的矿物质粉末，爆炸后形成持续数小时的浓厚烟幕，干扰敌方感知柱的化学信号检测。 |
| **哨戒刺** | 防御/反入侵 | 一簇朝各个方向伸出的尖刺，埋藏于地表下。当感知到震动时会瞬间弹射出去，刺穿靠近的生物或其他囊体。 |
| **榴散锥** | 面杀伤/反轻型 | 内部预埋大量硬质骨片或矿物碎片，爆炸后呈锥形散布，专门杀伤小型个体或破坏敌方薄皮的感知柱。 |
| **浮雷种** | 扩散/漂移雷 | 拳头大小，不固定于根脉网，直接漂浮在低空，随风缓慢漂移。触发后独立爆炸，负责向外围扩散杀伤区。 |
| **诱饵泡** | 欺骗/误导 | 外形与主战浮囊完全相同，但内部无炸药，只充满模拟敌方识别气味的化学物质。升空爆炸后释放误导信号，诱使敌方攻击空区。 |
| **哨啸弹** | 声学压制 | 囊体内部有特殊的狭缝结构，升空过程中气体高速通过狭缝产生刺耳尖啸，干扰依赖回声定位的生物与敌方的感知系统。 |
| **延爆管** | 延时/钻地 | 长管状，不像浮囊那样升空爆炸，而是沿根脉网缓慢蠕动，钻入敌方根脉网深处后才引爆，专门破坏地下通信与营养网络。 |

| 个体类型 | 功能 | 形态 |
|:---|:---|:---|
| **测距杆** | 精准定位 | 感知柱的增强型，高度可达10米以上，极细如竹竿。顶部有一组精密的气压孔阵列，通过压力差定位远处爆炸的方位与距离。 |
| **探照囊** | 光信号标记 | 半透明囊体，内部共生发光细菌。感知到敌方气味时间歇性发出微弱荧光，在浓暗中为攻击单位标记目标，每次只亮数秒。 |
| **超声哨** | 主动声波探测 | 囊体顶部有孔状开口，发出低频超声波脉冲，通过回波探测地形变化与不散发化学气味的非生物威胁。 |
| **传令管** | 远距离信号中继 | 特化的中空管状菌丝，内部充满液体与溶解的气体信号分子，可沿管道快速推送化学指令，速度远超普通根脉网的扩散。 |
| **播种囊** | 繁殖/扩张 | 拳头大的小球体，内部充满轻质孢子，成熟时裂开，孢子上浮到空中扩散至远方。 |
| **主战囊** | 核心攻击 | 直径2-8米的球状囊体，半埋于有机雪中。底部酶解有机物产生甲烷、氢气与高能焦油，储存至高压后释放锚绳缓慢上浮，在高空引爆。 |
| **多管霰** | 面杀伤覆盖 | 一个主囊体下连接12-20个微型子囊。触发时子囊依次喷出，散布至数百平方米区域，制造密集的爆裂焦油雨。 |
| **酸蚀囊** | 腐蚀突破 | 不爆炸。内部充满高浓度腐蚀性酶液，触发后向固定方向喷射液柱，专门烧穿对方根脉网的防御壳层。 |
| **锚雷囊** | 延迟陷阱 | 爆炸后不直接杀伤，而是喷射出数百根带倒钩的菌丝锚索，挂住经过的生物或其他囊体，将其拖拽沉入有机雪深处。 |
| **鱼雷梭** | 地下潜行攻击 | 鱼雷形囊体，在有机雪层中主动蠕动前进，由后方根脉网提供液压推力。速度极慢，每天仅移动数米，将装药直接运至敌方核心区引爆。 |
| **滚火囊** | 滚动纵火 | 球形囊体，脱离后向敌方阵地缓慢滚动，沿途破裂并释放粘稠的燃烧焦油，制造一条持续燃烧的火墙。 |
| **拦截囊** | 对空防御 | 感知到高空有物体接近时，快速向空中喷射一片致密粘液网 以及骨片，拦截坠落的残骸或入侵孢子。 |
| **阻塞囊** | 物理屏障 | 囊体外壁极厚，半埋在阵地边界。触发后膨胀变硬，形成不可逾越的坚硬障碍，堵塞敌方鱼雷梭与燃烧滚囊的路径。 |
| **烟幕囊** | 化学屏蔽 | 破裂时释放大量高密度惰性气体气溶胶，制造厚重的不透明气体屏障，干扰敌方感知柱对己方化学信号的识别。 |
| **诱饵囊** | 欺骗干扰 | 表面化学标记与己方核心根脉网相同，但内部无装药。吸引敌方攻击，消耗对方触发次数，暴露敌方感知范围。 |
| **堑壕根** | 冲击吸收 | 边界区域的根脉网特化变异，异常粗壮且内部充满空腔。空腔吸收爆炸冲击波，减少连片爆轰的链式扩散。 |
| **工厂结** | 加速装填 | 主脉上的肿大结节，内部共生高产酶菌株。战时被激活，快速分解有机雪并输送浓缩原料给附近浮囊。 |
| **气田囊** | 气体储备 | 巨大的地下储气腔，持续储存甲烷与氢气作为战时气体原料的战略储备库。若被引爆则造成巨大弹坑。 |
| **回收须** | 残骸回收 | 极细的无色触须，在每次战争平息后从根脉网伸出，爬过被爆炸撕裂的区域，回收未消耗的焦油、囊壁碎屑与敌方组织残片，重新分解利用。 |
| **焦油腺** | 装药合成 | 根脉网上附着的黏稠腺体，专门将从有机雪中提取的脂类与蛋白质转化为高能焦油状分泌物。 |

**关键特征：它们没有大脑。**  
整个炮台巢的行为由一套极其复杂的 **化学信号梯度** 和 **物理阈值系统** 驱动。就像一台由管道和阀门构成的计算机，它的“思考”就是液体在不同腔室间的流动和压力的积累。

### 三、攻击机制：慢蚀炸弹

#### 第一步：缓慢的装填

**主战浮囊** 是一个半埋在雪层中的囊体。它的底部伸入“有机雪”中，通过酶解作用持续分解雪中的有机物，产生 **甲烷、氢气、一氧化碳** 等易燃气体，以及 **高能焦油状分泌物**。这些气体和分泌物被储存在囊体内部，压力持续升高。

装填过程极其缓慢——**一个浮囊需要大约 6 到 10 天 才能达到攻击压力。**

在这段时间里，这个浮囊看起来和周围任何一块鼓包没有什么区别：不移动、不发声、不发光。

#### 第二步：地雷般的感应

当浮囊接近满压状态时，它的囊壁会变得极薄且极度敏感。感知柱会持续监测以下参数：

- **振动频率**：其他炮台巢浮囊破裂的声音、大型生物在地表拖行的震动、甚至远处另一个炮台巢被激发的冲击波。
- **化学信号**：敌方炮台巢释放的“识别标记”（一种特殊气味分子），或者在战斗中泄露的体液。
- **压力变化**：有生物踩踏或撞击到覆盖它的有机雪层。

这些信号会通过根脉网传播，激活浮囊表面的化学触发开关。

#### 第三步：浮空与引爆

一旦触发，浮囊会做两件事：

1. **释放锚绳**：连接它和根脉网的几条粗壮、强韧的纤维状附着结构会 **主动断裂**。同时，囊体内部的轻质气体产生的浮力使它 **缓慢地开始上升**。
2. **被动延迟引信**：囊体表面有一个特殊的 **压力敏感阀门**。当囊体上浮到一定高度（约 10-20 米），周围的外部气压降低到某个阈值时，阀门会打开，让外部的高氧空气进入囊内，与内部的焦油状分泌物和易燃气体瞬间混合，引发 **剧烈的爆炸**。

**结果：**  
这个浮囊像一颗从地下慢慢升起、在空中爆炸的炸弹。爆炸本身不大（相当于几十公斤炸药），但它会喷射出大量的 **高温焦油碎片**，这些碎片落在其他炮台巢的囊体上会引发连锁反应，或点燃有机雪层，制造一片火海。

### 四、硬编码式“战争”：行为就是规则

炮台巢之间的“战争”不是有意识的战略，而是 **由化学信号触发的机械式反应链**。这一切都是硬编码在它们的遗传和化学系统中的。

#### 识别与敌意

- 每个炮台巢的根脉网会分泌一种 **识别气味**（类似于一个化学指纹）。
- 其他炮台巢的感知柱能够检测这种气味。
- **规则一（硬编码）：** 当感知到 **非同源** 的识别气味浓度超过阈值时，自动进入“敌对态”。

#### 扩张与冲突

- 炮台巢通过播种囊不断向外扩散孢子，试图占领新的有机雪区域。
- 当两个炮台巢的根脉网在雪层下 **互相接触** 时，它们不是融合，而是：
    - **同步触发边界区域的浮囊装填加速**（化学信号刺激）。
    - **降低敌对浮囊的触发阈值**（变得更容易爆炸）。
    - 开始生产一种特殊的 **“穿透种子”**——这种种子会主动刺入对方的根脉网，窃取营养或释放毒素。

#### 战争实况：寂静的炮击

一场典型的“战争”是这样的：

1. 两个炮台巢的边界区域，双方埋设的浮囊开始密集装填。
2. 没有任何冲锋或嘶吼。只有无数个鼓包在十天里慢慢地鼓起来。
3. 当足够多的浮囊进入临界状态后，其中一个因为某个微小的扰动（也许是风，也许是一只恰好路过的甲壳动物）爆炸了。
4. 爆炸的冲击波和化学信号 **触发边界线上所有其他浮囊**，形成一次链式爆轰。
5. 这场爆炸可能持续数小时，像一个缓慢燃烧的导火索，在数万平方米的区域里逐一点燃。
6. 爆炸平息后，双方的根脉网都会受损，但活下来的感知柱会 **重新评估气味浓度**，然后各自退后一点，留下一个充满弹坑和焦痕的缓冲区。

**没有胜利者，没有失败者。**  
它们只是执行了程序。然后继续。

### 五、与生态系统的互动

- **生物雪的清道夫：** 它们通过分解有机雪层，加速了营养物质在整个深渊层的循环。没有它们，有机雪可能堆积到几十米深。
- **地表恐怖的制造者：** 对于任何胆敢在地表行走的生物来说，炮台巢的领地就是雷区。一步走错，就会触发脚下那个鼓包，然后在几十秒后，看着一颗炸弹从你面前缓缓升起。
- **信息素网络：** 整个深渊层的炮台巢通过根脉网形成了一个 **超大规模的化学信号网络**。虽然每个巢都是敌对的，但它们的行为实际上协调了整个地表层的能量流动和物质分布。它们“不知道”自己在做什么，但它们做完了。

---

- **“死”的还在战斗：** 一个炮台巢被完全摧毁后，它埋在雪层下的根脉网碎片仍然带有化学记忆。如果另一片根脉网接触到它，仍然会触发敌对反应，导致残骸区成为永久性的低烈度冲突带。
- **太空可见的伤痕：** 从高空俯瞰，天洋星的地表并非平滑的。那些炮台巢持续交战的区域，由于有机雪被反复烧焦和抛起，形成了一片片巨大的、暗褐色的“疤痕”——像是星球表面长出的苔藓斑。
- **文明级的硬编码：** 这种炮台巢可能已经存在了数亿年。它们的战争从未停止，也从未升级。没有一方演化出压倒另一方的能力，因为“完全胜利”这个状态 **不在它们的化学指令集里**。
